Giveaway IG sammelt die Instant-Gaming-Giveaways, die noch offen sind, prüft, welche aktiv sind, und nimmt für dich daran teil, eine Seite nach der anderen, in einer Oberfläche im Stil eines Sternenhimmels. Du meldest dich einmal an; danach genügt jeden Monat ein Klick auf **Automatisch starten**.

> [!NOTE]
> Open-Source-Projekt, **nicht mit Instant Gaming verbunden**, ohne Affiliate- oder Empfehlungslinks.

> [!TIP]
> Die App gibt es auf Deutsch: Wähle die Sprache im Einrichtungsassistenten oder unter **Einstellungen**. Die Screenshots auf dieser Seite zeigen die englische Version.

## 🚀 Erste Schritte

1. **Lade** `GiveawayIG.exe` (Windows) oder `GiveawayIG-x86_64.AppImage` (Linux) von der Seite [Releases](https://github.com/michoko999/Instant-Gaming-Giveaway/releases/latest) **herunter**.
2. **Lege sie in einen eigenen Ordner**, zum Beispiel `Dokumente\GiveawayIG`. Deine Einstellungen werden daneben gespeichert.
3. **Starte sie.** Ein kurzer Assistent führt dich:
   - **Konto verbinden**: Die Instant-Gaming-Seite öffnet sich in der App; melde dich wie gewohnt an (dein Passwort tippst du auf deren Seite, nie in der App);
   - die App lädt die Listen und prüft, welche Giveaways offen sind;
   - wähle deinen Modus und dein Tempo.
4. Klicke auf **Automatisch starten** (oder **Manueller Modus**) und lass sie arbeiten. Komm nächsten Monat wieder 🌙

Voraussetzungen: Windows 10 oder 11 mit Microsoft Edge WebView2 (in Windows 11 und aktuellem Windows 10 bereits enthalten). Unter Linux (x86_64) machst du das AppImage mit `chmod +x GiveawayIG-x86_64.AppImage` ausführbar und startest es: Deine Einstellungen werden ebenfalls daneben gespeichert.

## ⚠️ Bevor du den automatischen Modus nutzt

Die Teilnahmebedingungen von Giveaways verbieten oft Teilnahmen durch „Bots“. Der automatische Modus kann daher dazu führen, dass Teilnahmen annulliert werden oder sogar dein Instant-Gaming-Konto gesperrt wird. **Die Entscheidung liegt bei dir**; im Zweifel nutze den manuellen Modus.

Der **vorsichtige Modus** (Einstellungen → *Vorsichtiger Modus (empfohlen)*) senkt das Risiko, ohne es zu beseitigen:

- mindestens 8 Sekunden zwischen zwei Giveaways und eine begrenzte Anzahl pro Sitzung (standardmäßig 40);
- die Sitzung stoppt sofort, wenn die Seite eine Warnung zeigt oder mehrere menschliche Überprüfungen verlangt, sowie nach mehreren Fehlern hintereinander;
- Giveaways, an denen du diesen Monat schon teilgenommen hast, werden nicht erneut geöffnet;
- die Listen werden ohne dein Konto und in gemäßigtem Tempo geprüft.

Die App versucht nicht, sich als Mensch auszugeben: keine vorgetäuschten Mausbewegungen, kein Lösen von Captchas.

## 🛡️ Virenscanner und „Der Computer wurde durch Windows geschützt“

Version 2 wurde neu gebaut, damit sie nicht mehr wie Schadsoftware aussieht:

- eine echte native ausführbare Datei (Rust + Tauri), die sich **nicht selbst entpackt** wie die alte PyInstaller-Version;
- **keine simulierten Tastatureingaben** und keine Tastatur-Hooks: Die Klicks passieren im eigenen Fenster der App;
- keine Schreibzugriffe auf `%TEMP%`, kein Autostart mit Windows, keine Systemänderungen.

Solange die Datei nicht signiert ist (ein kostenloser Antrag auf Codesignatur bei der SignPath Foundation ist geplant, siehe [Signaturrichtlinie](docs/CODE_SIGNING_POLICY.md)), kann Windows SmartScreen bei einer neuen Version „Der Computer wurde durch Windows geschützt“ anzeigen. Das ist eine Reputationswarnung, kein Virenfund: Stammt die Datei von der Releases-Seite und stimmt ihr Fingerabdruck, klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.

## 🔒 Datenschutz

- Dein Passwort tippst du auf der Seite von Instant Gaming, im eingebauten Fenster. Die App sieht und speichert es nie.
- Die Sitzung (Cookies) bleibt auf deinem PC in `GiveawayIG-data\webview`. **Abmelden** in den Einstellungen löscht sie.
- Keine Telemetrie, kein Konto, keine Werbung. Die App verbindet sich nur mit:

| Adresse | Wozu |
|:--|:--|
| `instant-gaming.com` | Giveaways prüfen und teilnehmen |
| `gaming-cdn.com` | das Profilbild deines Kontos laden |
| `raw.githubusercontent.com`, `jv-actu.com`, `ledemondujeu.com` | Giveaway-Listen laden (jede Quelle lässt sich abschalten) |
| `api.github.com`, `github.com` | prüfen, ob es eine neue Version gibt, und sie herunterladen (abschaltbar) |

## ❓ Häufige Fragen

<details>
<summary><b>Warum kann ich nur einmal im Monat teilnehmen?</b></summary>
<br />
Das ist die Regel von Instant Gaming: eine Teilnahme pro Giveaway und Monat. Die App berücksichtigt das und öffnet ein Giveaway erst im nächsten Monat wieder.
</details>

<details>
<summary><b>Wie füge ich Giveaways hinzu, die nicht in den Listen stehen?</b></summary>
<br />
Klicke unter <b>Giveaways</b> auf <b>Links einfügen</b> und füge Instant-Gaming-Links oder Codes ein (der Text drumherum wird ignoriert). Du kannst auch eine Datei importieren oder unter <b>Einstellungen → Giveaway-Quellen</b> eine Online-Liste oder Webseite hinzufügen. Um sie mit allen zu teilen, öffne ein <a href="https://github.com/michoko999/Instant-Gaming-Giveaway/issues">Issue</a>, dann landen sie in der gemeinsamen Liste.
</details>

<details>
<summary><b>Kann ich mehrere Instant-Gaming-Konten nutzen?</b></summary>
<br />
Ja: Klicke oben rechts auf dein Konto, dann auf <b>Konto hinzufügen</b>, und melde dich im sich öffnenden Fenster damit an. Jedes Konto hat seine eigene Anmeldung, seine eigene Monatsübersicht und seinen eigenen Verlauf; über das Menü oben rechts wechselst du zwischen ihnen. Giveaway-Regeln erlauben oft nur eine Teilnahme pro Person: Nutze ein Konto pro Person.
</details>

<details>
<summary><b>Was passiert, wenn eine Überprüfung (Captcha) erscheint?</b></summary>
<br />
Das Giveaway wird zurückgestellt und die Sitzung läuft weiter. Am Ende zeigt die Zusammenfassung die Giveaways, die du von Hand abschließen musst, mit einem Button, um jede Seite zu öffnen.
</details>

<details>
<summary><b>Wo liegen meine Einstellungen? Wie fange ich neu an?</b></summary>
<br />
Im Ordner <code>GiveawayIG-data</code> neben <code>GiveawayIG.exe</code> (oder in deinem Windows-Benutzerordner, falls dieser Ort schreibgeschützt ist). Willst du die App verschieben, verschiebe beides zusammen. Für einen Neuanfang schließe die App und lösche diesen Ordner.
</details>

<details>
<summary><b>Wie aktualisiere ich?</b></summary>
<br />
Wenn eine neue Version veröffentlicht wird, erscheint oben in der App ein Hinweis: Klicke auf <b>Aktualisieren</b>. Du kannst die neue <code>GiveawayIG.exe</code> auch von Hand herunterladen und die alte ersetzen. In beiden Fällen bleiben deine Daten erhalten.
</details>

<details>
<summary><b>Wo ist die alte Python-Version?</b></summary>
<br />
Im Ordner <a href="legacy/">legacy</a>. Sie wird nicht mehr gepflegt.
</details>

## 🛠️ Aus dem Quellcode bauen

Voraussetzungen: [Node.js 22](https://nodejs.org), stabiles [Rust](https://rustup.rs) und unter Windows die C++-Build-Tools von Visual Studio ([Tauri-Voraussetzungen](https://tauri.app/start/prerequisites/)).

```bash
npm ci
npm run tauri dev                 # im Entwicklungsmodus starten
npx tauri build --no-bundle       # ausführbare Datei: src-tauri/target/release/giveaway-ig.exe
```

```bash
npm run check                                        # TypeScript-/Svelte-Typen
cargo test --manifest-path src-tauri/Cargo.toml      # Tests des Rust-Kerns
```
